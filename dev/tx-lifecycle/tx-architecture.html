The log contains two kinds of messages: user transactions (blue) and internal system messages (orange: FlushBlock, TriesAdded, BlockUploaded, AttachDatabase, DetachDatabase).
Every node consumes the same log and derives the same state. That's the core guarantee.
A node's "position" is just its current offset. The msgId = (epoch << 48) | offset.
